# Soorian Metal Landing

صفحه لندینگ مدرن برای **سورین متال** — تولیدکننده پیشرو محصولات فلزی صنعتی و دکوراتیو در مشهد.

## 🔗 لینک‌ها

- **سایت اصلی:** [soorianmetal.com](https://soorianmetal.com/)
- **فروشگاه آنلاین:** [soorianmetal.com/shop](https://soorianmetal.com/shop/)
- **درباره ما:** [soorianmetal.com/about](https://soorianmetal.com/about/)

## 🛠️ تکنولوژی‌ها

| تکنولوژی | کاربرد |
|---|---|
| **Vue 3** | Composition API |
| **Vite** | Build Tool |
| **CSS3** | Grid, Flexbox, Animations |
| **SVG** | آیکون‌ها و نشان‌ها |
| **Vazirmatn** | فونت فارسی |

## 📦 نصب و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرا در حالت توسعه
npm run dev

# ساخت نسخه نهایی
npm run build

# پیش‌نمایش نسخه نهایی
npm run preview
