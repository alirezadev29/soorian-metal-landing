# Soorian Metal Landing Page

صفحه لندینگ مدرن برای شرکت **سورین متال** — تولیدکننده پیشرو محصولات فلزی صنعتی و دکوراتیو در مشهد.

## 🔗 لینک‌ها

- **سایت اصلی:** [soorianmetal.com](https://soorianmetal.com/)
- **فروشگاه آنلاین:** [soorianmetal.com/shop](https://soorianmetal.com/shop/)
- **درباره ما:** [soorianmetal.com/about](https://soorianmetal.com/about/)

## ✨ ویژگی‌ها

- طراحی ریسپانسیو (موبایل، تبلت، دسکتاپ)
- پشتیبانی کامل از RTL و زبان فارسی
- آیکون‌های SVG داخلی (بدون وابستگی به اینترنت)
- انیمیشن‌های نرم
- هدر ثابت با تغییر در اسکرول
- منوی موبایل همبرگری
- رنگ‌بندی هماهنگ با لوگوی برند
- فرم و لینک‌های تماس سریع

## 🛠️ تکنولوژی‌ها

- Vue 3 (Composition API)
- Vite
- CSS3 (Grid + Flexbox)
- Vazirmatn Font

## 📦 نصب و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرا در حالت توسعه
npm run dev

# ساخت نسخه نهایی
npm run build

# پیش‌نمایش نسخه نهایی
npm run preview
